# CS-482: Distributed Systems Engineering (Spring 2026)
Instructor: Prof. Sarah Lin | Department of Computer Science & Engineering

## Course Description
CS-482 provides a rigorous foundation in the design, consensus guarantees, fault tolerance, and scalability of distributed software systems. Topics include logical time, state machine replication, peer-to-peer networks, distributed storage, and consistency models.

## Grading Distribution
- **Programming Labs (4 Projects)**: 45%
  - Lab 1: Remote Procedure Call (RPC) Framework in Go
  - Lab 2: Raft Consensus Algorithm (Leader Election & Log Replication)
  - Lab 3: Fault-Tolerant Distributed Key-Value Store
  - Lab 4: Sharded Transactional Database with Two-Phase Commit (2PC)
- **Midterm Examination**: 20%
- **Final Project (Distributed Streaming Engine or Custom Protocol)**: 25%
- **Class Participation and Paper Critiques**: 10%

## Required Reading & Textbooks
1. Martin Kleppmann, *Designing Data-Intensive Applications* (O'Reilly, 2017).
2. Selected papers: Lamport (1978) on Logical Clocks; Ongaro & Ousterhout (2014) on Raft Consensus; Chang et al. (2006) on Bigtable.

## Late Policy and Academic Honor Code
Each student is granted three (3) slip days that may be utilized across the four programming labs without penalty. Subsequent late submissions incur a 15% deduction per 24-hour period. All submitted lab code is analyzed using automated plagiarism detectors.
